# Review Reply Templates

## Accepted and Fixed
`Thanks for the review. Fixed in <file>:<line>. Verification: <command/result>.`

## Needs Clarification
`I can address this, but I need one clarification: <question>. Current interpretation: <assumption>.`

## Intentional Non-Change
`I reviewed this and kept current behavior because <reason>. Risk tradeoff: <tradeoff>.`

## Deferred to Follow-Up
`I agree with this point. I created follow-up item <id/link> because scope of this PR is <scope>.`

## Reply Quality Rules
- Reference concrete files or commands.
- Avoid generic “done” replies.
- Separate facts from assumptions.
- If unresolved, state blocker and owner explicitly.
