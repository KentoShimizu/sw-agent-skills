# Testing TDD Trigger And Examples

## Positive Trigger Signals
- Teams want strict red-green-refactor execution.
- Design should emerge through failing tests and small increments.
- Refactor risk must be controlled by micro-cycle evidence.

## Non-Matching Signals
- Tests are only added after implementation completion.
- Primary task is load/performance/operations design.

## Example Requests That Should Trigger This Skill
- `Implement this feature using strict TDD cycles.`
- `Use red-green-refactor to evolve design safely.`
- `Reduce refactor risk through test-first increments.`

## Minimal Deliverable Example
1. Cycle scope and constraints
2. Alternative cycle-size trade-offs
3. Selected TDD strategy
4. Red-green-refactor evidence chain
5. Residual risk and next-cycle actions
