# Principle Quality Heuristics

## Good Principle Characteristics
- Actionable: guides concrete design decisions.
- Stable: survives short-term visual trends.
- Bounded: clarifies where it applies and where it does not.
- Reviewable: can be checked with observable evidence.

## Common Failure Patterns
- Slogan-only wording without checks.
- Conflicting principles with no precedence rule.
- Principles that encode one specific UI solution instead of intent.
